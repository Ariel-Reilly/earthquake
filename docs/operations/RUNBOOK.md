## 2. 演示数据刷新（**每场演示前 5 分钟内执行**）

```powershell
$env:APPLY='1'; node scripts/delivery/verify-demo-data-refresh.mjs
```

- 目的：把演示库「在线设备数 / 预警时间」刷到当前，避免 `DeviceOnlineChecker` 5 分钟心跳把设备打回离线。
- 验收：脚本 PASS 后，**在页面**确认「6 在线 + 预警时间为本地今天」；不要只看脚本。
- 只读校验（不写库）：去掉 `APPLY='1'` 即为 dry-run。

## 3. 演示前检查清单

- [ ] 演示数据已刷新（上一步），页面确认 6 在线 + 本地今天预警时间；
- [ ] AI 综合研判已触发一次实时推理（避免首屏显示旧 `10/24` 落库评分）；
- [ ] 区域专项关联预警：若演示讲到，提前说明「不可点击」或跳过；
- [ ] 地图右上角提示条不遮挡关键内容。

## 4. 已知演示边界（非故障）

- 设备心跳 5 分钟回落 → 在线数会自然下降，属预期；
- 外部地图约 320 条 `ERR_BLOCKED_BY_ORB`、NSMC/NMC 天气源超时/404 → 页面有降级文案；
- drift / multimodal 后端代理为显式 501（L-01）；AI 训练 / 备份校验 / 资产申请为「未实现」语义。
