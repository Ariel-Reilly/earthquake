# 值班员一页纸操作卡（B7-3）

> 适用版本：DisasterGuard / 御灾智巡 交付快照 v1.8.0+
> 面向：甲方值班员、现场演示人 · 2026-11-13

## 1. 登录

| 项 | 说明 |
|---|---|
| 地址 | 生产为甲方域名（HTTPS 由上线日配置）；本地演示 `http://localhost:5173` |
| 账号 | 上线日必须由运维统一改密并分发，**不要使用开发默认口令**（见 `PRODUCTION_HARDENING.md` §五） |
| 时间显示 | **跟随浏览器本地时区**（A6-5 决策）。演示/值班前确认本机时区与系统时间正确；服务端日志与调度仍按 `TZ=Asia/Shanghai` |

## 2. 预警处置（最常用）

1. 左侧「预警与处置 → 预警中心」查看列表；红色预警会全屏警报 + 声音。
2. 点「确认收到」：警报**彻底静音**；被浏览器自动播放拦截时点「开启警报声」。
3. 「派发」选择处置单位/人员；处理完成后「关闭预警」，**必须填写关闭原因**，取消不落库。
4. 需要看依据：进入预警详情 → 「AI 分析详情」。AI / 指标 / 影像任一类缺失时页面给降级提示（`ai=null`、占位说明），**不会伪造数据或图片**。

## 3. 会签与代签

1. 「灾害研判 → 会签与转派」发起会签，选择会签人（最多 5 人）。
2. 会签人各自确认/驳回；冒用他人 `signerId` 会被 403 拒绝。
3. **管理员代签已按本次决策开启**（`sign:proxy` 仅授予 admin）：管理员可替专家确认，
   每一次代签都会写 `warn` 审计日志，可在应用日志/审计中追溯。其他角色仍不可代签。

## 4. 时相对比（灾前 / 灾后）

1. 「监测与态势 → 时相对比」，选灾害点或手填 AOI，设定灾前 / 灾后时间窗口。
2. 点「开始对比」→ 生成两期影像 → 计算差异热力图 → 查看变化率与 Top 热点。
3. **没有真实卫星影像时只显示降级原因，不展示演示噪声图或假差异图**（B1-4）。
   需要配置 CDSE / GEE 凭证或保证 ai-service 能访问公开 STAC 源，见 `docs/CDSE_SETUP.md`。

## 5. 常见异常与边界

| 现象 | 处理 |
|---|---|
| WS 断线 | 页面出现重连提示，轮询兜底继续更新；恢复网络后自动重连 |
| AI 服务不可用 | 相关模块显示降级提示，不影响预警主流程；检查 ai-service 容器/端口 |
| 页面显示「演示数据」角标 | 该统计尚未接真实聚合（见 `KNOWN_LIMITATIONS.md` L-17），演示时按 `DEMO_SCRIPT.md` 兜底话术说明 |
| 接口 501 / 「二期能力」 | 属明确产品边界（C 类），不是故障；不要承诺本次交付已实现 |

- [ ] admin 登录正常、首页与预警中心有数据
- [ ] 按 `DEMO_SCRIPT.md` 走一遍关键路径（≤20 分钟）
