## 九、核心建议总结

1. **建立"演示模式"明确标识**：mock 模式下在页面顶部或角标明确显示"演示模式"，让用户知道数据不是真实的
2. **API 失败时不要静默降级**：应显示错误提示或"暂无数据"，而不是悄悄展示假数据
3. **统一配置管理**：建立 `src/config/` 目录集中管理 API 地址、超时时间、阈值等
4. **统一枚举管理**：建立 `src/constants/` 目录定义业务状态、角色、类型等枚举
5. **建立设计系统**：颜色、间距、字体等样式 token 统一用 CSS 变量管理
6. **代码质量门禁**：使用 ESLint 规则拦截 magic number、硬编码字符串等问题
