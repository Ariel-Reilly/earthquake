阶段 A · 面包板搭建验证版

目标：先用面包板把整套接起来、跑出效果；验证通过后，再照"阶段 B 镀锡板版"焊成永久装置
两块 YD-ESP32-23 V1.3 · 同一份固件，只改 NODE_ROLE · 串口 115200
你现在就在阶段 A，不用碰电烙铁。 面包板插错拔了重来，零基础最合适。等这一版的数字、预警都跑通了，再打开《阶段 B · 镀锡板焊接版》（WIRING_CARD.html），按里面的"从面包板移植"一节把线一根根搬过去焊死。
两阶段只有一处不同：配电（3V3/GND/5V 怎么分）——阶段 A 用面包板的轨，阶段 B 用镀锡板焊出来的区。信号脚接线两阶段完全一样，不用重来。
如果手上现在只有一块板：先只做第 5 章的板①，把温湿度、两个超声波、继电器跑通；板②等第二块板到货再接。

0.3 桌面怎么摆

  1. 沙盘在后、电脑在前，两块板固定在沙盘靠你这一侧的外边框（板①靠水槽，板②靠坡体）。
  2. 面包板放在两块板中间，当"配电中心"。
  3. 电脑 USB 线从桌子前面绕到板子的 COM 口；5V2A 电源放在面包板旁边。
  4. 手机放旁边——每接完一个模块立刻拍一张照，这是以后最可靠的"接线记忆"，移植到镀锡板时也要靠它。

1先认识线：公头、母头、三种杜邦线

判断方法：捏住线头看金属端——尖针是公，套筒是母

1.1 一条铁律

针配孔，针配针要用"母对母"，针配面包板孔要用"公对母"。
  • ESP32 板子的两排针 = 公头；传感器模块的针 = 公头；面包板的孔 = 母。
  • 所以：板 ↔ 模块 用 母对母；板/模块 ↔ 面包板 用 公对母（公头那端插面包板）。

1.2 确认你买的三排线是哪种

  1. 拿一根看两头金属端：两头都是套筒 = 母对母；一头针一头孔 = 公对母；两头针 = 公对公。
  2. 本手册 板↔模块用母对母、接面包板用公对母。缺哪种补哪种。

1.3 怎么插、怎么拔

  1. 插：捏住线头根部硬塑料，垂直对准针按到底；别捏线身斜插。
  2. 拔：捏根部垂直拔，左右轻晃松动，别拽线身。
  3. 插好轻拉确认不松。松线是"时好时坏"的元凶。

1.4 颜色约定（定死，别混用）

颜色永远代表接到
橙3.3V板 3V3 / 面包板 3V3 轨
红5V板 5V / 5V2A 正极 / 5V 轨
黑地板 GND / 公共地
蓝第一信号Trig / OUT / I-O / SDA / DIN
黄第二信号Echo / SCL
例外：舵机自带的线红=5V、棕=地、橙=信号——这里橙是信号，别接到 3V3。

2三种接线方法

2.1 针配针 → 母对母杜邦线

  1. 按丝印认清两端针脚（看字不看位置）。
  2. 母头套住模块针，另一端套住 ESP32 对应数字的针。
  3. 轻拉两端确认紧；拍照。

2.2 板针 → 面包板 → 模块 → 用公对母杜邦线

用在哪里：所有需要 3.3V 的模块取电，以及 5V 分配。板上 3V3 只有两个，必须借面包板"复制"出很多个。
面包板三条规则
  1. 两侧的长条"轨"（红线、蓝线旁）是整条连通的：把电引到轨上任意一点，整条轨都有电。
  2. 中间那片区域每 5 个横向孔连通、纵向不通——本手册只用两侧轨。
  3. 注意：有些面包板上下（或左右）两条同色轨内部不通，要用一根杜邦线桥接。接完用万用表通断档量一下。

2.3 螺丝端子压线 → 剥线 + 螺丝刀

用在哪里：继电器两侧端子、端子排。杜邦线插不进去。
  1. 线头剥皮约 5mm；
  2. 螺丝逆时针拧松；
  3. 铜丝插到底，太细就对折成两股；
  4. 拧紧后轻拉线，拉不动才算好。

3找到针脚：板子的排列规律

  1. 按数字找，不要按位置数。每个 GPIO 号直接印在针旁。
  2. 5V 和 GND 在 COM 口那一端（你一直插线的 Type-C 口）；两个 3V3 在另一端，挨着 RST。
  3. GND 有好几个，任意一个都是同一个地。
  4. GPIO1、GPIO2 也引出来了（网上按 DevKitC-1 的教程说这俩没引出，对你不成立）。
  5. 两个 Type-C：COM 是串口（一直用它），USB / USB-OTG 是原生口，始终插 COM。
找不到数字时：手机开闪光灯正对板子俯拍放大。不要凭记忆插。

4先搭配电（这步不做，3.3V 不够用）

4.1 面包板分电：把 2 个 3V3 变成很多个

目标：把板子的一个 3V3"复制"成面包板上一整条轨，让所有 3.3V 模块取电。
  1. 一根 公对母 橙线：母头插板① 3V3，公头插面包板上红轨。
  2. 一根 公对母 黑线：母头插板① GND，公头插上蓝轨。
  3. 若面包板上下两条蓝轨不通，插一根短线桥接。
  4. 万用表量：上红轨对 GND 应是 3.3V（不是 5V）。量错立刻拔电检查。

4.2 5V2A 电源出线

  1. 先别插 220V。剪掉圆头（或用 DC 转接线），按标签 + 在圆心 → 内芯正极(5V)、外皮编织层负极。
  2. 通电用万用表确认内芯对外皮是 5V，然后断电。
  3. 红线(5V+) 插面包板下红轨；黑线(GND−) 插下蓝轨（已和板子 GND 连通）。
面包板四条轨： 上红轨 = 3.3V（来自板① 3V3） 上蓝轨 = GND（来自板① GND） 下红轨 = 5V（来自 5V2A 正极） 下蓝轨 = GND（与上蓝轨桥接，来自电源负极） 板② 也用同一块面包板：再引一根 3V3 线过去即可
功率警报：2A 总共。两块板约 1A，两个舵机堵转可到 1.4A，30 颗灯带全白约 1.8A。灯带压低亮度只亮几颗，两个舵机别同时动。

6继电器、水泵、电源

6.1 继电器端子压线

这块不是排针，是两组螺丝端子：输入侧 DC+ / DC− / IN，输出侧被外壳挡住，经验上中间是 COM，两边 NO / NC。
端子接哪里用什么线、怎么接
DC+面包板 5V 轨公对母线，公头插面包板，另一端剥皮压螺丝
DC−面包板 GND 轨同上
IN板① 14母对母线，母头套板针，另一端剥皮压螺丝；多为低电平吸合
COM5V2A 正极剥皮线压端子（可与 DC+ 并到同一 5V 点）
NO水泵红线(+)水泵 USB 剪掉后剥出的红线，剥皮压进来
NC空着不接—

6.2 先测"咔哒"，再接水泵

  1. 先把水泵红线从 NO 上拿掉，只接输入侧三根线。
  2. 上传：
    #define R 14
void setup(){ pinMode(R, OUTPUT); }
void loop(){
  digitalWrite(R, LOW);  delay(1000);
  digitalWrite(R, HIGH); delay(2000);
}
  3. 每 2 秒"咔哒"一声 + 小灯亮灭 → 低电平吸合，正确。
  4. 没反应 → 把 LOW/HIGH 对调再传。
  5. 一直吸合不松 → 立刻断电，查 DC+ 和 DC− 是否碰在一起。

6.3 水泵 USB 线怎么处理

  1. 断电剪掉 USB 插头。剥开外皮，通常红=+、黑=−，万用表确认。
  2. 红线 → 继电器 NO；黑线 → 公共地（面包板 GND 轨）。
  3. 泵标称 3V，给 5V 会偏快。每次开 30 秒以内。
  4. 出水口接铜雾化喷头，朝水槽固定。

7走线规矩、上电顺序、验收

7.1 排列与走线七条规矩

  1. 按模块接，不按颜色接。一次一个模块，接完立刻拍照。
  2. 信号与电源分两束：蓝/黄走模块正面，橙/红/黑走背面。
  3. 短线在上、长线在下。
  4. 线从板子外侧绕，别压住 USB、BOOT、RST。
  5. 每 5 根线打一个扎带，扎在离板 5cm 处。
  6. 两端贴标签：写 A-TRIG、C-SERVO1；两只超声波最容易混。
  7. 主线束贴后边框走：用缠绕管把电源束包成一股，沿沙盘后边框横穿。

7.2 上电顺序（每次都一样，别跳步）

  1. 全部接完，断电状态复查：5V 有没有插进数字脚、+/− 有没有接反。
  2. 万用表量：3V3 轨对 GND = 3.3V，5V 轨对 GND = 5V，两轨不短路。
  3. 插两块板 USB（先不开串口），摸一遍所有模块——有热的立刻拔电。
  4. 再插 5V2A 电源给舵机、灯带、继电器。
  5. 最后开串口监视器（115200）看数据。

7.3 逐层验收清单（什么时候算"验证成功，可以转镀锡板"）

层做到什么怎么确认成功
1每块板单独出数串口滚 {"node":"Node-A","water_mm":...}，手在探头前移动数值变化
2网关认得python gateway/sandbox_gateway.py --mode serial --print-only --steps 5 打出设备名
3大屏有曲线后端开 EMQX_ENABLED=true，大屏数值跟着变
4预警弹出加水 + 开泵，达到规则阈值弹窗
5硬件联动需补 MQTT→串口桥，目前链路未通
第 1–4 层都通过了，就可以转阶段 B 了。 打开《阶段 B · 镀锡板焊接版》（WIRING_CARD.html），照最后一节"从面包板移植到镀锡板"把线一根根搬过去焊死。信号脚接线两阶段完全一样，只需重做配电部分。
联调前记得把 config.yaml 的 serial 配两条、把不存在的 Node-B 设备注释掉。
建议动手顺序：备齐面包板和线 → 面包板搭三轨并量电压 → 板①两个超声波（就能测水位）→ DHT11 / BMP280 → 继电器 → 板②。每接一组拍一张照。有任何一步发烫或短路，立刻断电。
