阶段 B · 镀锡板焊接版

从"桌上有哪些东西"到"每根线怎么焊" · 面向零基础 · 可打印后放在板子旁边照做
两块 YD-ESP32-23 V1.3 · 同一份固件，只改 NODE_ROLE · 串口 115200
先看这里：这份是"阶段 B"，别急着用。 正确顺序是先在面包板上把整套搭起来、跑出效果（用《阶段 A · 面包板搭建验证版》WIRING_BREADBOARD.html），确认第 1–4 层验收都通过后，再照本文件焊成永久装置。
两阶段只有"配电"不同：A 用面包板的轨，B 用镀锡板焊出来的区。信号脚接线完全一样，所以移植时信号线基本不用动，见文末"从面包板移植到镀锡板"。第一次焊务必先看 2.4 节。
如果手上现在只有一块板：先只做第 5 章的板①，把温湿度、两个超声波、继电器跑通；板②等第二块板到货再接。

0.3 先搞懂你的镀锡板：哪些孔是连着的

镀锡板（万能板/洞洞板）上每个孔周围有一圈铜箔焊盘。关键要分清两种：

  • 独立孔板：每个孔互不相连，要自己用导线把该连的孔焊起来。
  • 连体孔板：相邻 2 个、3 个孔或整行/整列内部已用铜箔连好（常标 "2-hole / 3-hole / row connected"）。分电省事得多。
怎么判断？万用表拨到蜂鸣（通断）档，两根表笔点相邻两个孔：响了就是连通，不响就是独立。沿着一排量几下，画出你的板子哪儿连、哪儿不连。
强烈建议：第一次焊就买整行连通的镀锡板。把一整行当一个"电源轨"，焊一个点，整行都有电，逻辑跟面包板一样，只是要焊。

0.4 桌面怎么摆

  1. 沙盘在后、电脑在前；两块板固定在沙盘靠你这一侧的外边框（板①靠水槽，板②靠坡体）。
  2. 镀锡板放在两块板中间，当"配电中心"；烙铁架放在右前方，烙铁线别跨过工作区。
  3. 电脑 USB 线从桌子前面绕到板子的 COM 口。
  4. 手机放旁边——焊完每一组立刻拍一张照，镀锡板焊错不好查，照片是唯一可靠的记录。

1先认识线：公头、母头、两种接法用的线

判断方法：捏住线头看金属端——尖针是公，套筒是母

1.1 一条铁律

针配孔。ESP32 板的针、模块的针、镀锡板上焊的排针，全是"公头"；两个公头之间要用母对母杜邦线。
所以本手册里，插拔的地方一律用母对母杜邦线；焊到镀锡板上的，是剥了皮的裸线（单芯/多股），不是带插头的杜邦线。

1.2 确认你买的三排杜邦线是哪种

  1. 拿一根看两头金属端：两头都是套筒 = 母对母（最常用）；一头针一头孔 = 公对母；两头针 = 公对公。
  2. 本手册绝大多数连接用母对母。如果你的三排里没有母对母，去补一排。

1.3 焊到镀锡板上的线怎么准备

  1. 用剥线钳/美工刀把线头外皮剥掉 3–5mm，露出铜丝。
  2. 多股线把铜丝捻紧，单芯线直接弯个小钩或折一下。
  3. 蘸一点助焊剂，用电烙铁给铜丝预先挂一层锡（搪锡），防止散股、便于焊接。
  4. 颜色照 1.5 的约定走。

1.4 怎么插、怎么拔（别把针弄歪）

  1. 插：捏住线头根部的硬塑料，垂直对准针按到底；别捏线身斜插，会掰歪针。
  2. 拔：捏根部垂直拔，左右轻晃松动，别拽线身（会把线从插头里拉脱）。
  3. 插好轻拉确认不松。松线是"时好时坏"的元凶。

1.5 颜色约定（定死，别混用）

颜色永远代表接到
橙3.3V板 3V3 / 镀锡板 3V3 区
红5V板 5V / 5V2A 正极 / 5V 区
黑地板 GND / 公共地
蓝第一信号Trig / OUT / I-O / SDA / DIN
黄第二信号Echo / SCL
例外：舵机自带的线红=5V、棕=地、橙=信号——这里橙是信号，别接到 3V3。保留原色，不要换。

2三种接线方法 + 焊接基本功

2.1 针配针 → 母对母杜邦线

用在哪里：ESP32 到各模块的所有连接（信号 + 供电）。
  1. 按丝印认清两端针脚（看字不看位置）。
  2. 母头套住模块针，另一端母头套住 ESP32 对应数字的针。
  3. 轻拉两端确认紧；拍照。

2.2 镀锡板配电 → 焊接

用在哪里：把 1 个 3V3 变成很多个、分配 5V、做公共地。这是本版的核心，也是难度最高的一环。

整体思路（记住这张图，后面都按它走）：

ESP32 ──母对母杜邦线──▶ [镀锡板上的公排针]
                            │
                      （板背面焊线连通）
                            │
        ┌───────────────────┼──────────────────┐
     3V3区                 GND区               5V区
      │                     │                   │
   母对母杜邦线          母对母杜邦线        母对母杜邦线
      │                     │                   │
   各模块电源脚        各模块地脚          舵机/灯带/继电器
  1. 在镀锡板上规划三块区域：3V3 区、GND 区、5V 区，各焊若干公排针作对外接口。
  2. 用裸线在板背面把同区的焊盘/孔焊连起来（连体孔板靠铜箔，独立孔板要另焊跳线）。
  3. ESP32 的 3V3/GND 用母对母杜邦线引到对应区的排针；5V2A 红线焊进 5V 区、黑线焊进 GND 区。
  4. 各模块从对应区的排针用母对母杜邦线取电。
为什么不把信号也焊上去？信号脚要经常改、要调试。焊死了一改就得拆焊，零基础很容易把板子焊坏。只把"配电"焊死，信号保持杜邦线插拔，这是最稳的分工。

2.3 螺丝端子压线 → 剥线 + 螺丝刀

用在哪里：继电器两侧端子、端子排。杜邦线插不进去。
  1. 线头剥皮约 5mm（别剥太长，外露铜丝多了容易短路）。
  2. 螺丝逆时针拧松（不用取下）。
  3. 铜丝插到底，看不到铜丝为止；太细就对折成两股再插。
  4. 拧紧后轻拉线，拉不动才算好。

2.4 焊接基本功（第一次焊，务必先读，最好先拿废板练几个点）

标准五步法
  1. 预热：烙铁插电预热 3–5 分钟；恒温款设 330–360℃。烙铁头先在海绵上蹭掉旧锡，再吃一层新锡（发亮的锡才传热好）。
  2. 固定：用尖嘴钳或镊子把线头贴住焊盘，烙铁尖同时接触焊盘和线，加热 1–2 秒。
  3. 送锡：把焊锡丝送到焊盘与线的接触点（不是送到烙铁尖上），锡熔化后包围焊点，撤走锡丝。
  4. 移烙铁：锡铺开后立刻移开烙铁，保持线不动 2 秒等它凝固（这时候一动就虚焊）。
  5. 检查：好焊点=光亮、圆锥形、锡把线脚包住；发暗、有裂纹、线能晃 = 虚焊，重新加锡焊。
焊镀锡板的三个特别注意
  1. 别让相邻孔连锡：焊完用万用表量一下相邻的不同区（如 3V3 与 GND）是否不该通却通了——短路会烧板。
  2. 焊盘别反复烫：一个点最多烫 3 秒，烫久了铜箔会脱落，脱落了这个孔就废了。
  3. 焊完断电、冷却再接线插拔；热锡甩出去会烫伤。
安全
  • 烙铁头 300℃ 以上，绝不碰手、不碰线皮、不搁桌面，不用就放回烙铁架。
  • 焊锡偶尔溅出，戴普通眼镜；保持通风；桌面上别放易燃物。
  • 用完先关电源，等烙铁冷却再收。第一次焊建议先看一个 5 分钟的焊接教学视频，比文字直观。

3找到针脚：板子的排列规律

  1. 按数字找，不要按位置数。每个 GPIO 号直接印在针旁（"8"就是一个数字）。
  2. 5V 和 GND 在 COM 口那一端（你一直插线的 Type-C 口）。
  3. 两个 3V3 在另一端，挨着 RST 键。
  4. GND 有好几个，任意一个都是同一个地。
  5. GPIO1、GPIO2 也引出来了（网上按 DevKitC-1 的教程说这俩没引出，对你不成立）。
  6. 两个 Type-C：COM 是串口（一直用它），USB / USB-OTG 是原生口，始终插 COM。
找不到数字时：手机开闪光灯正对板子俯拍放大。不要凭记忆插——插错一格的现象是"程序正常、模块完全没反应"。

4先搭配电（这步不做，3.3V 不够用）

4.1 在镀锡板上规划并焊出三条区

目标：把 ESP32 的一个 3V3、一个 GND、和 5V2A 的正负极，焊到镀锡板上，扩展出很多个接口。
  1. 分区：板子左侧划一片做 3V3、中间做 GND、右侧做 5V，每区预留 4–6 个接口。用记号笔在板边写清楚。
  2. 焊排针：每区焊 1–2 排公排针（针朝上），这就是以后插杜邦线的接口。
  3. 连通同区：
    • 连体孔板：同区的孔若已在铜箔上连通，就不用额外焊线；用万用表确认。
    • 独立孔板：用裸线在板背面把同区各焊盘逐个焊连成一条。
  4. 万用表验收：同区内任意两点必须通；3V3 与 GND、5V 与 GND 之间必须不通。这步能提前抓出短路。

4.2 接电源进板

  1. ESP32 的 3V3 → 母对母杜邦线 → 镀锡板 3V3 区排针（橙）。
  2. ESP32 的任意 GND → 母对母杜邦线 → 镀锡板 GND 区排针（黑）。
  3. 5V2A 电源：先别插 220V，剪掉圆头（或用 DC 转接线），按标签 + 在圆心 → 内芯是正极(5V)、外皮编织层是负极；万用表确认通电后内芯对外皮是 5V。断电状态下把红线焊进 5V 区、黑线焊进 GND 区，焊点包上热缩管/胶带。
镀锡板三区最终： 3V3 区 = ESP32 的 3V3（约 3.3V，给传感器供电） GND 区 = ESP32 GND + 5V2A 负极（公共地） 5V 区 = 5V2A 正极（给舵机/灯带/继电器） 通电后万用表量：3V3 区对 GND = 3.3V；5V 区对 GND = 5V
功率警报：2A 总共。两块板约 1A，两个舵机堵转可到 1.4A，30 颗灯带全白约 1.8A。灯带压低亮度只亮几颗，两个舵机别同时动，否则一动作板子就重启。

6继电器、水泵、电源：三个最容易出错的操作

6.1 继电器端子压线

这块不是排针，是两组螺丝端子：输入侧 DC+ / DC− / IN，输出侧被外壳挡住，经验上中间是 COM，两边 NO / NC。
端子接哪里用什么线、怎么接
DC+镀锡板 5V 区裸线焊到 5V 区，另一端剥皮压进螺丝
DC−镀锡板 GND 区裸线焊到 GND 区，另一端压端子
IN板① 14母对母杜邦线，母头套板针，另一端剥皮压进螺丝；多为低电平吸合
COM5V2A 正极剥皮线压端子（可与 DC+ 并到同一 5V 点）
NO水泵红线(+)水泵 USB 剪掉后剥出的红线，剥皮压进来
NC空着不接—

6.2 先测"咔哒"，再接水泵

  1. 先把水泵红线从 NO 上拿掉，只接输入侧三根线。
  2. 上传：
#define R 14
void setup(){ pinMode(R, OUTPUT); }
void loop(){
  digitalWrite(R, LOW);  delay(1000);
  digitalWrite(R, HIGH); delay(2000);
}
  1. 每 2 秒"咔哒"一声 + 小灯亮灭 → 低电平吸合，正确。
  2. 没反应 → 把 LOW/HIGH 对调再传（有的模块高电平触发）。
  3. 一直吸合不松 → 立刻断电，查 DC+ 和 DC− 是否碰在一起。

6.3 水泵 USB 线怎么处理

  1. 断电剪掉 USB 插头（端子夹不住）。剥开外皮，通常红=+、黑=−，万用表确认。
  2. 红线 → 继电器 NO；黑线 → 公共地（镀锡板 GND 区）。
  3. 泵标称 3V，给 5V 会偏快。每次开 30 秒以内，摸泵体不烫即可；长时间要加 3V 降压模块。
  4. 出水口接铜雾化喷头，朝水槽固定，别对着板子喷。

7走线规矩、上电顺序、验收

7.1 排列与走线七条规矩

  1. 按模块接，不按颜色接。一次一个模块，焊/接完立刻拍照，再下一个。
  2. 信号与电源分两束：蓝/黄走模块正面，橙/红/黑走背面，两束不交叉。
  3. 短线在上、长线在下：离板近的模块最后接，线压最上层，拆的时候不用动别人。
  4. 线从板子外侧绕，别压住 USB、BOOT、RST——压住后每次烧程序都要拆线。
  5. 每 5 根线打一个扎带，扎在离板 5cm 处，形成"根 → 束 → 主干"三级。
  6. 两端贴标签：写 A-TRIG、C-SERVO1；两只超声波最容易混，混了就是"一个永远读不到"。
  7. 镀锡板背面走线要整齐：同区连线尽量贴板、不交叉；焊完检查相邻区没被锡连起来。

7.2 上电顺序（每次都一样，别跳步）

  1. 全部接完，断电状态复查：5V 有没有插进数字脚、+/− 有没有接反。
  2. 万用表量：3V3 区对 GND = 3.3V，5V 区对 GND = 5V，两区之间不短路，各焊点不虚焊。
  3. 插两块板 USB（先不开串口），摸一遍所有模块——有热的立刻拔电。
  4. 再插 5V2A 电源给舵机、灯带、继电器。
  5. 最后开串口监视器（115200）看数据。

8从面包板移植到镀锡板（阶段 A → B 怎么做不返工）

前提：阶段 A 的第 1–4 层验收都通过了（板子出数、网关认得、大屏有曲线、预警能弹）。没通过就别焊——焊上去改起来麻烦。

8.1 核心原则：信号线不动，只换配电

两阶段的接线只有"供电从哪来"变了：

  • 信号线（蓝/黄，接 GPIO 的）：ESP32 针 ↔ 模块针，两阶段一模一样，一根都不用改。
  • 电源线（橙/红/黑，去 3V3/5V/GND 的）：原来插在面包板轨上，现在要改到镀锡板的区上——只有这些要重做。
所以移植 = 把"电源线的面包板那一头"从轨上拔下来，改成接到镀锡板对应区。模块那一头和所有信号线都不碰。

8.2 移植五步（按顺序做，每步都验证）

  1. 先焊好镀锡板三区：照第 4 章，在镀锡板上焊出 3V3 / GND / 5V 三区并焊好公排针，万用表验收（同区通、异区不通、电压对）。这一步不拆面包板，两套配电暂时并存。
  2. 把镀锡板接进系统：ESP32 的 3V3、GND 用母对母杜邦线引到镀锡板对应区；5V2A 的红黑线焊进 5V / GND 区。此时面包板仍插着，先别拔。
  3. 逐个模块把电源挪过去：一次只搬一个模块——把它的电源线（橙/黑/红）从面包板轨拔下，改插镀锡板对应区排针；搬一个就上电验证这个模块还正常，再搬下一个。全部搬完前不要拔面包板。
  4. 最后拆面包板：所有模块都挪到镀锡板、逐个验证通过后，才把面包板上的线全拔掉、撤走面包板。杜邦线能留用的留用。
  5. 整体验收：照 7.2、7.3 重跑一遍上电顺序和五层验收，确认移植没引入虚焊或短路。
为什么不一次性全拔全焊？那样一旦出问题，你不知道是哪根线、哪个焊点错了。逐个搬、逐个验，永远知道自己改的是哪一处——这是零基础最省时间的做法。

8.3 移植时最容易犯的三个错

  1. 把模块信号线和电源线搞混：只挪电源（橙/红/黑接 3V3/5V/GND 的），蓝/黄信号线留在原地别动。
  2. 舵机/灯带的 5V 忘了挪：它们不经过 ESP32，直接取 5V。移植后红线要接到镀锡板 5V 区（或端子排），棕/黑线接 GND 区。
  3. 共地断了：镀锡板 GND 区必须同时连着 ESP32 的 GND 和 5V2A 的负极。移植完用万用表量：镀锡板 GND 区对 ESP32 任一 GND 必须通（蜂鸣响）。
建议动手顺序：先在阶段 A 把效果跑通 → 备齐焊接工具 → 拿废板练几个焊点 → 照第 8 章逐个模块移植到镀锡板 → 每搬一个验一个。有任何一步发烫或短路，立刻断电。
